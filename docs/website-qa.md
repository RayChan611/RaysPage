# 我的个人网站问答

## 1. 这个网站用的什么架构？为什么用这个？

我用的是 **Astro**，采用静态站点生成的方式，也就是在发布前把网页生成好。

当时选 Astro，是因为我想陆续把自己拍的照片、写的文章放到网站上。我预计这些内容会越积越多，所以想找一种以后加内容也好维护的做法，Astro 比较适合。

- **发文章时，我可以专心写内容。** 新文章写成一个文件，Astro 会套用共用的排版，生成文章页。首页的最新文章、文章目录和搜索索引也会从同一份内容更新。
- **照片多了，摄影集也能按系列整理。** 我可以维护每组照片的顺序和说明，页面用共用的画廊模板展示。网站还能按屏幕大小提供不同尺寸的图片，让手机浏览时少下载一些数据。
- **图文页面提前生成，浏览和发布都更简单。** 浏览器收到网页就能开始显示正文和排版，照片按需要加载。每次更新后重新构建一次，EdgeOne 就可以分发生成好的网页和图片。
